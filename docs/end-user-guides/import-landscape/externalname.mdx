# External Name

Crossplane uses the [`external-name` annotation](https://docs.crossplane.io/latest/guides/import-existing-resources/) to indicate and link external resources.

Most Cloud Foundry resources return a unique GUID as their identifier. The following table summarizes the external-name format for every provider resource, where to find the identifier, and any adoption notes.
