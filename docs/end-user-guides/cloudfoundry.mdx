# Cloud Foundry (CF)

The guides in our end user guides section will walk you through a complete end-to-end use case for managing Cloud Foundry resources with Crossplane as code.

<a href="https://doc.crds.dev/github.com/SAP/crossplane-provider-cloudfoundry" target="_blank" className="button button--primary button--lg" style={{marginBottom: '1.5rem', display: 'inline-block'}}>Browse CF CRDs ↗</a>

To realize the use case, you'll:

- [Order](/docs/crossplane-provider-cloudfoundry/docs/end-user-guides/order-cf-environment) a managed Cloud Foundry Environment in your BTP Subaccount.
- [Install and Configure](/docs/crossplane-provider-cloudfoundry/docs/end-user-guides/configure-provider-cf) the Cloud Foundry provider to manage Resources in your Cloud Foundy Environment
- [Manage Orgs & Spaces](/docs/crossplane-provider-cloudfoundry/docs/end-user-guides/manage-orgs-spaces) in your Cloud Foundry Environment
- [Deploy Workload](/docs/crossplane-provider-cloudfoundry/docs/end-user-guides/deploy-workload-provider-cf) into your Cloud Foundry Environment

Additionally topics you can learn about:

- [Import Cloud Foundry Org](/docs/crossplane-provider-cloudfoundry/docs/end-user-guides/import-landscape/import-without-yaml) which helps you export existing Cloud Foundry resources and import them into your control plane
